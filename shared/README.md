the first project** (vertical-slice work on the chosen lead title).

  project; supports paid chapter expansions without breaking saves
  (see `docs/BRAND.md` monetization model).

  across the slate.
- **Art import pipeline** — pixel-perfect Godot 4 setup,
  nearest-neighbor filtering, fixed pixels-per-unit (see
  `docs/ART-BIBLE.md`).
- **Localization table format** — UI string keys + translation table,
  English at launch, community translations later.
