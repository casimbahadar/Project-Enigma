# Grafted — Build-A-Beast Bio-punk RPG

*Phase 0 — `DESIGN.md` lands in Phase 1.*

> A bio-punk world where **Grafters** splice creature parts to create
> new beings. You don't catch creatures — you **build** them from
> essences harvested from defeated beasts.

## Quick spec

- **Genre**: party-combat RPG with creature crafting
- **Verb**: build / graft
- **Factions**: the Pure Strain Order vs. the Grafter's Guild
- **Example creature**: Mireling (its venom gland → Toxic affinity)
- **Identity**: every player's roster is unique → screenshot-driven
  reach
- **Meta loop**: crafting depth, not collection breadth
