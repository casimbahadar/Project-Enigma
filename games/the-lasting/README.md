# The Lasting — Time-Loop JRPG

*Phase 0 — `DESIGN.md` lands in Phase 1.*

> A small kingdom is stuck in a 30-day loop before catastrophe. You
> remember each loop; no one else does. Recruit and re-recruit a party
> each cycle, accumulating only what *you* know.

## Quick spec

- **Genre**: ATB-style party RPG with knowledge-gating across loops
- **Verb**: remember
- **Cast**: 12 recruitable companions, each carrying one of 12
  original birth-sign archetypes (light zodiac flavor — narrative
  rather than mechanical)
- **Identity**: time-loop fantasy; FF-style story + FE-style supports
  + Outer Wilds-style knowledge gating
