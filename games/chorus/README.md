# Chorus — Music-Powered Tactical RPG

*Phase 0 — `DESIGN.md` lands in Phase 1.*

> After "**the Hush**," sound is sacred and songs literally power
> magic. Your party is a **Choir**; each member is a voice or
> instrument; adjacency on the grid composes harmonies that fuel
> combos.

## Quick spec

- **Genre**: FE-style grid tactics
- **Verb**: compose (positioning *is* the magic system)
- **Factions**: Brass City, Stringfen, the Silent Order
- **Identity**: positioning-as-music; audio-forward, share-friendly
  (TikTok-native)
